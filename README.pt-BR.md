[English](README.md) · **Português**

Engenheira de software full stack de Porto Alegre. Trabalho como desenvolvedora há cerca de três anos, principalmente com Node.js, TypeScript, Java e React.

A maior parte do meu trabalho é no backend: APIs, bancos de dados e integrações entre serviços. Gosto de entender o que acontece quando algo dá errado (um retry, um timeout, duas requisições ao mesmo tempo) e garantir que o sistema continue fazendo a coisa certa.

### Projeto em destaque

**[fintech-wallet-platform](https://github.com/mikaelapg/fintech-wallet-platform)**: uma carteira digital com transferências entre usuários. Usa ledger de dupla entrada no PostgreSQL, transferências idempotentes, travas de linha para lidar com requisições simultâneas e o padrão outbox para publicar eventos no RabbitMQ. Front em React, roda com Docker, tem manifests de Kubernetes e CI no GitHub Actions.

### Tecnologias

- **Backend:** Node.js, TypeScript, Java, Spring Boot, APIs REST
- **Frontend:** React, TypeScript, Tailwind CSS
- **Bancos de dados:** PostgreSQL, MongoDB, Redis
- **Mensageria:** RabbitMQ
- **DevOps:** Docker, Kubernetes, GitHub Actions, AWS
