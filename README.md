Most of my work is on the backend: APIs, databases and the integrations between services. I like understanding what happens when things go wrong (a retry, a timeout, two requests at the same time) and making sure the system still does the right thing.

### Featured project

**[fintech-wallet-platform](https://github.com/mikaelapg/fintech-wallet-platform)**: a digital wallet with transfers between users. It uses a double-entry ledger in PostgreSQL, idempotent transfers, row locking to handle concurrent requests, and the outbox pattern to publish events to RabbitMQ. Frontend in React, runs with Docker, has Kubernetes manifests and CI on GitHub Actions.
